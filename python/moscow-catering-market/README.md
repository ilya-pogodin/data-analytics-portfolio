# Изучение рынка заведений общественного питания Москвы

Исследование для инвесторов, которые планируют открыть заведение в Москве и выбирают формат, район и ценовой сегмент.

**Стек:** Python, pandas, seaborn, matplotlib, phik

## Что сделано

1. Загрузка данных, оценка пропусков и дубликатов, приведение типов
2. Предобработка: категории, административные округа, часы работы, ценовые сегменты, посадочные места
3. Исследовательский анализ - восемь задач с визуализациями
4. Итоговый вывод и рекомендации заказчику

## Восемь задач исследования

1. Какие категории заведений представлены в данных и сколько объектов в каждой
2. Распределение заведений по административным округам Москвы
3. Соотношение сетевых и несетевых заведений - в целом и в разрезе категорий
4. Количество посадочных мест: поиск аномалий и выбросов
5. Рейтинги заведений и распределение средних оценок по категориям
6. С чем сильнее всего коррелирует рейтинг - матрица корреляции phik
7. Топ-15 популярных сетей Москвы и их средние рейтинги
8. Вариация среднего чека по районам, отдельно Центральный округ

Плюс дополнительный блок: круглосуточный формат работы и цена чашки капучино.

## Сложности и как я их решил

**Матрица корреляции была построена не тем методом.** В задаче 6 я закодировал категории через one-hot и посчитал коэффициент Пирсона. Код отрабатывал без ошибок, поэтому проблема была не видна: Пирсон на дамми-переменных меряет связь рейтинга с каждой отдельной категорией, а не силу связи с признаком целиком, и ранжировать признаки по такой матрице нельзя. Переписал на φₖ из библиотеки `phik`: признаки берутся в исходном виде, категория и округ остаются одним столбцом, числовые помечаются через `interval_cols`. Порядок связей после этого изменился, вывод переписан под новые числа.

**Выбросы среднего чека были только на словах.** В задаче 8 я упомянул выбросы в тексте, но нигде их не показал - проверить утверждение по тетради было нельзя. Добавил в начало задачи гистограмму и диаграмму размаха с `showfliers=True`, такую же пару после обрезки по 99-му перцентилю и таблицу самых дорогих заведений. Стало видно, где именно находится хвост: 104 заведения, то есть 3,3 % выборки.

**В рекомендациях остались цифры, которых нет в коде.** Доли дорогих заведений по округам и названия сетей-конкурентов в дешёвом сегменте я взял из промежуточных прикидок, а в финальной версии тетради этих расчётов не осталось. Числа были верные, но воспроизвести их читатель не мог. Добавил перед итоговым выводом раздел «Расчёты для итоговых рекомендаций» - теперь каждое число из рекомендаций считается прямо в ноутбуке.
